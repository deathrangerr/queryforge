🎯 Key Features

  • SAML 2.0 authentication
  • Multi-database support (PostgreSQL, MySQL, Oracle)
  • Advanced SQL editor with syntax highlighting
  • Transaction management with safety confirmations
  • Export results (Excel, CSV, JSON, SQL)
  • Professional dark/light mode UI
  • Session management with timeouts
  • Query history and notifications
  • Phase A: Emergency Mode & Lock Visualization
  • Phase A: Performance Monitor & Maintenance Tools

🛡️ Security Features

  • User credentials approach (no shared accounts)
  • Single session per user enforcement
  • 5-minute inactivity timeout
  • 60-minute maximum session duration
  • Automatic transaction rollback on errors
  • Query validation for mutating operations
  • Secure session storage
  • Activity monitoring
  • Emergency read-only mode
  • Statement timeout controls

⚡ Performance

  • 10,000 row result limit
  • Query cancellation support
  • On-demand schema loading
  • Efficient session management
  • Progress indicators
  • Optimized data transfer
  • Fast UI rendering
  • Minimal memory footprint
  • Top queries analysis (pg_stat_statements)
  • Unused index detection
