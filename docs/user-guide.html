Getting Started

1. Login

  1. Navigate to the application URL
  2. You'll be redirected to your SAML identity provider for authentication
  3. Enter your corporate credentials
  4. After successful authentication, you'll be redirected back to the application

2. Connect to Database

  1. Click the "Connect" button in the top toolbar
  2. Fill in the connection form:
    • Database Type: PostgreSQL, MySQL, or Oracle
    • Host: Database server hostname or IP
    • Port: Database port (default: 5432 for PostgreSQL, 3306 for MySQL, 1521 for Oracle)
    • Database: Database name
    • Username: Your database username
    • Password: Your database password
  3. Click "Connect"
  4. Wait for the connection confirmation
💡 Tip: Your credentials are stored only in your session and are never persisted to disk.

SQL Editor

Working with Query Tabs

  • Add Tab: Click the "+" button to create a new query tab
  • Switch Tabs: Click on any tab to switch to it
  • Rename Tab: Double-click the tab name to rename it
  • Close Tab: Click the "×" button on the tab

Writing Queries

  • Type your SQL query in the editor
  • Syntax highlighting helps identify keywords, strings, and comments
  • Line numbers appear on the left for easy reference
  • Brackets are automatically matched

Executing Queries

  • Execute All: Click "Execute" button or press Ctrl+Enter
  • Execute Selection: Select text and press Ctrl+Enter
  • Multiple Statements: Separate with semicolons (;)

Query Tools

  • Format: Click "Format" to auto-format your SQL with proper indentation
  • Explain: Click "Explain" to see the query execution plan
-- Example query SELECT u.id, u.name, u.email, COUNT(o.id) as order_count FROM users u LEFT JOIN orders o ON u.id = o.user_id WHERE u.created_at >= '2026-01-01' GROUP BY u.id, u.name, u.email ORDER BY order_count DESC LIMIT 10;

Object Browser

Browsing Database Objects

  1. Click on the object type tabs: Tables, Views, Functions, Indexes, Sequences, Triggers
  2. Objects are grouped by schema
  3. Click the ▶ arrow to expand a schema
  4. Click on any object name to view its details

Searching Objects

  • Use the search box at the top of the Object Browser
  • Type to filter objects by name
  • Search works across all visible objects in the current tab

Viewing Object Details

When you click an object, a modal window shows:

  • Tables: Columns, data types, constraints
  • Views: View definition SQL
  • Functions: Function source code, parameters, return type
  • Indexes: Index definition, columns, type
  • Sequences: Current value, increment, min/max values
  • Triggers: Trigger definition, timing, event

Results Viewer

Viewing Results

  • Query results appear in a table below the editor
  • Column headers show the column names
  • Row count and execution time displayed at the top

Pagination

  • Select rows per page: 50, 100, 500, or 1000
  • Use Previous and Next buttons to navigate pages
  • Current page and total pages shown in the middle

Sorting

  • Click any column header to sort by that column
  • First click: ascending order (▲)
  • Second click: descending order (▼)
  • Third click: remove sorting

Filtering

  • Use the search box above the results table
  • Type to filter rows across all columns
  • Filtering is case-insensitive
  • Clear the search box to show all results

Row Selection

  • Check the box in the first column to select a row
  • Check the header checkbox to select all visible rows
  • Selected rows are highlighted
  • Selection count shown at the top

Exporting Data

Export Formats

Excel (.xlsx)

  • Click "Export to Excel"
  • File downloads automatically
  • Includes all columns and data types
  • Formatted for easy viewing in Excel

CSV

  • Click "Export to CSV"
  • Standard comma-separated values format
  • Can be opened in Excel, Google Sheets, or any text editor

JSON

  • Click "Export to JSON"
  • Structured data format
  • Useful for APIs and data processing

Copy as INSERT

  1. Select the rows you want to export (use checkboxes)
  2. Click "Copy as INSERT"
  3. Enter the target table name when prompted
  4. SQL INSERT statements are copied to your clipboard
  5. Paste into your SQL editor or another tool
⚠️ Note: All exports are logged for compliance purposes, including user, timestamp, row count, and format.

Transaction Management

Starting a Transaction

BEGIN;

Committing Changes

COMMIT;

Rolling Back Changes

ROLLBACK;

Transaction Safety

  • Destructive queries (DELETE, DROP, TRUNCATE) show a confirmation dialog
  • Errors automatically rollback the transaction
  • Always test in DEV environment first
  • Use transactions for multi-statement operations
💡 Best Practice: Wrap multiple related statements in a transaction:
BEGIN; UPDATE accounts SET balance = balance - 100 WHERE id = 1; UPDATE accounts SET balance = balance + 100 WHERE id = 2; COMMIT;

DBA Tools

Accessing DBA Tools

  • Click the "DBA Tools" tab in the main navigation
  • Three sub-tabs available: Sessions, Locks, Users

Session Monitor

  • View all active database sessions
  • See currently running queries
  • Check session duration and state
  • Kill sessions by clicking the "Kill" button
  • Enable "Auto-refresh" to update every 5 seconds
⚠️ Caution: Killing sessions can interrupt active work. Use with care. All session kills are logged.

Lock Monitor

  • View all database locks
  • Identify blocking queries
  • See lock types and modes
  • Check if locks are granted or waiting
  • Find the process holding each lock

User Management

  • List all database users and roles
  • View user privileges (superuser, createdb, etc.)
  • Check account status (active/locked)
  • See role memberships

Search Everywhere

Opening Search

  • Press Ctrl+Shift+F
  • Or click the 🔍 Search button in the toolbar

Using Search

  1. Type in the search box
  2. Results filter in real-time as you type
  3. Search across all object types: tables, views, functions, indexes, sequences, triggers
  4. Results show object icon, name, type, and schema
  5. Click any result to view its details

Closing Search

  • Press Escape
  • Or click outside the search modal
  • Or click the × button

Environment Safety

Environment Banner

  • Green (DEV): Development environment - safe for testing
  • Yellow (UAT): User acceptance testing - use caution
  • Red (PROD): Production environment - extreme caution required

Read-Only Mode

  • Toggle read-only mode in production to prevent accidental changes
  • When enabled, only SELECT queries are allowed
  • Mutating queries (INSERT, UPDATE, DELETE) are blocked

Destructive Query Confirmation

  • DELETE, DROP, TRUNCATE queries show a confirmation dialog
  • Review the query carefully before confirming
  • Risk level is automatically analyzed

Session Management

Session Timeouts

  • Inactivity Timeout: 5 minutes of no activity
  • Maximum Duration: 60 minutes total
  • Query Protection: Sessions are extended during query execution

Session Warnings

  • You'll receive a warning before session expiration
  • Click "Stay Connected" to extend your session
  • Or let it expire to automatically disconnect

Disconnecting

  • Click the "Disconnect" button in the toolbar
  • Your database connection is closed
  • Your session is cleared
  • You remain logged in via SAML

Logging Out

  • Click the "Logout" button
  • You're disconnected from the database
  • Your session is cleared
  • You're logged out of SAML

Tips & Best Practices

Query Performance

  • Use LIMIT to restrict result sets
  • Add WHERE clauses to filter data
  • Use EXPLAIN to analyze query plans
  • Create indexes for frequently queried columns

Data Safety

  • Always test queries in DEV first
  • Use transactions for multi-statement operations
  • Double-check WHERE clauses in UPDATE/DELETE
  • Use read-only mode when just viewing data
  • Export data before making bulk changes

Productivity

  • Use multiple tabs for different queries
  • Rename tabs to organize your work
  • Use Search Everywhere (Ctrl+Shift+F) to quickly find objects
  • Format queries for better readability
  • Save frequently used queries in a text file

Security

  • Never share your database credentials
  • Log out when finished
  • Use strong database passwords
  • Review activity logs regularly
  • Report suspicious activity immediately

Troubleshooting

Connection Issues

  • Verify hostname and port are correct
  • Check your database credentials
  • Ensure you have network access to the database
  • Confirm the database is running

Query Errors

  • Check SQL syntax
  • Verify table and column names
  • Ensure you have necessary permissions
  • Review error message for details

Session Expired

  • Click "Connect" to reconnect
  • Enter your credentials again
  • Your query tabs are preserved

Getting Help

  • Check the documentation
  • Review logs for error details
  • Contact your database administrator
  • Report issues to the support team
