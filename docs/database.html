Phase A: Advanced DBA Tools ✨ NEW

Emergency Mode

Critical incident response controls in the DBA Tools header:

  • Read-Only Mode: One-click toggle to block all write operations
  • Statement Timeout: Set 10-second timeout for all queries
  • Visual Indicators: Buttons change color when active
  • Confirmation Required: All changes require confirmation
  • Security Logging: All emergency mode changes logged
⚠️ Permissions Required:
  • PostgreSQL: ALTER DATABASE or SUPERUSER
  • MySQL: SUPER privilege
  • Oracle: ALTER SYSTEM

Lock Graph Visualization

Visual blocking chain analysis in the Locks tab:

  • Blocking Chain Tree: Visual representation of lock dependencies
  • Root Blocker: Identified with red badge
  • Blocked Sessions: Shown with orange badges
  • Query Preview: See queries for each lock
  • Depth Indication: Indentation shows blocking depth

Maintenance Tools

Daily DBA maintenance in the new Maintenance tab:

Bloat Analysis

  • Table bloat percentage calculation
  • Dead tuple counts
  • Table size display
  • Color-coded indicators (red >20%, orange <20%)
  • One-click VACUUM and ANALYZE buttons

Autovacuum Status

  • Last vacuum/autovacuum timestamps
  • Last analyze/autoanalyze timestamps
  • Vacuum and autovacuum counts
  • Sorted by most recent activity
⚠️ VACUUM Warning: VACUUM operations may briefly lock tables. Always shows confirmation dialog before execution.

Performance Monitor

Query and index analysis in the new Performance tab:

Top Queries

  • Top 20 queries by total execution time
  • Call counts and statistics
  • Mean, max, and total execution times
  • Row counts returned
  • Query preview with full text on hover

Unused Indexes

  • Indexes with zero scans
  • Index size display
  • Excludes primary keys
  • Sorted by size (largest first)
  • Candidates for removal
📋 Setup Required:

Performance Monitor requires pg_stat_statements extension:

CREATE EXTENSION pg_stat_statements; -- In postgresql.conf: shared_preload_libraries = 'pg_stat_statements' pg_stat_statements.track = all

Restart PostgreSQL after configuration changes.
