Authentication Endpoints

POST /api/connect

Connect to a database with user credentials

Request Body:

{ "dbType": "postgresql", "host": "localhost", "port": 5432, "database": "mydb", "username": "user", "password": "pass" }

Response:

{ "success": true, "message": "Connected successfully" }

POST /api/disconnect

Disconnect from database and clear session

Response:

{ "success": true, "message": "Disconnected successfully" }

Query Endpoints

POST /api/query

Execute SQL query

Request Body:

{ "query": "SELECT * FROM users LIMIT 10" }

Response:

{ "success": true, "results": [ {"id": 1, "name": "John", "email": "john@example.com"}, {"id": 2, "name": "Jane", "email": "jane@example.com"} ], "rowCount": 2, "executionTime": 45 }

POST /api/explain

Get query execution plan

Request Body:

{ "query": "SELECT * FROM users WHERE email = 'test@example.com'" }

Response:

{ "success": true, "plan": [ {"QUERY PLAN": "Seq Scan on users (cost=0.00..35.50 rows=10 width=100)"}, {"QUERY PLAN": " Filter: (email = 'test@example.com')"} ] }

DBA Endpoints

POST /api/db/sessions

List active database sessions

Response (PostgreSQL):

{ "success": true, "sessions": [ { "pid": 12345, "user": "dbuser", "database": "mydb", "state": "active", "query": "SELECT * FROM users", "duration": "00:00:05" } ] }

POST /api/db/locks

List database locks

Response:

{ "success": true, "locks": [ { "locktype": "relation", "database": "mydb", "relation": "users", "mode": "AccessShareLock", "granted": true, "pid": 12345 } ] }

POST /api/db/kill-session

Terminate a database session

Request Body (PostgreSQL):

{ "pid": 12345 }

Request Body (Oracle):

{ "sid": 123, "serial": 456 }

Response:

{ "success": true, "message": "Session terminated successfully" }
⚠️ Security: This action is logged with user, timestamp, and target session details.

POST /api/db/users

List database users and roles

Response:

{ "success": true, "users": [ { "username": "dbuser", "superuser": false, "createdb": false, "createrole": false, "canlogin": true } ] }

Phase A: Advanced DBA Endpoints ✨ NEW

POST /api/db/emergency-mode

Toggle emergency mode (read-only or statement timeout)

Request Body:

{ "action": "readOnly", // or "timeout" "enable": true // or false to disable }

Response:

{ "success": true }
⚠️ Security: Requires ALTER DATABASE (PostgreSQL) or SUPER (MySQL) privilege. All actions logged to security log.

POST /api/db/lock-graph

Get blocking chain visualization

Response:

{ "lockGraph": [ { "blocker_pid": 12345, "blocked_pid": 12346, "blocker_query": "UPDATE users SET ...", "blocked_query": "SELECT * FROM users ...", "depth": 1 } ] }

POST /api/db/performance

Get query performance statistics and unused indexes

Response:

{ "topQueries": [ { "query": "SELECT * FROM large_table", "calls": 1000, "total_exec_time": 45000.5, "mean_exec_time": 45.0, "max_exec_time": 150.2, "rows": 50000 } ], "unusedIndexes": [ { "schemaname": "public", "tablename": "users", "indexname": "idx_unused", "size": "128 MB", "idx_scan": 0 } ] }
📋 Requirement: Requires pg_stat_statements extension to be installed and configured.

POST /api/db/bloat

Get table bloat analysis

Response:

{ "bloat": [ { "schemaname": "public", "tablename": "large_table", "size": "1024 MB", "n_dead_tup": 50000, "bloat_pct": 25.5 } ] }

POST /api/db/autovacuum-status

Get autovacuum status for all tables

Response:

{ "status": [ { "schemaname": "public", "tablename": "users", "last_vacuum": "2026-02-19 10:30:00", "last_autovacuum": "2026-02-19 11:00:00", "last_analyze": "2026-02-19 10:30:00", "last_autoanalyze": "2026-02-19 11:00:00", "vacuum_count": 5, "autovacuum_count": 10 } ] }

POST /api/db/vacuum

Execute VACUUM or VACUUM ANALYZE on a table

Request Body:

{ "table": "public.users", "analyze": true // false for VACUUM only }

Response:

{ "success": true }
⚠️ Warning: VACUUM may briefly lock tables. Requires VACUUM privilege. All operations logged to activity log.

Error Responses

Standard Error Format

{ "success": false, "error": "Error message description" }

Common HTTP Status Codes

  • 200 OK: Request successful
  • 400 Bad Request: Invalid request parameters
  • 401 Unauthorized: Not authenticated
  • 403 Forbidden: No session or insufficient permissions
  • 500 Internal Server Error: Server or database error

Example Error Responses

// No active session { "success": false, "error": "No active database connection" } // Query syntax error { "success": false, "error": "syntax error at or near \"SELCT\"" } // Permission denied { "success": false, "error": "permission denied for table users" } // Extension not installed (Performance Monitor) { "error": "pg_stat_statements extension not installed", "instructions": "Run: CREATE EXTENSION pg_stat_statements;" }

Request Headers

Required Headers

Content-Type: application/json Cookie: connect.sid=...

Session Management

All API requests require a valid session cookie obtained after SAML authentication. The session is automatically managed by the browser.

Rate Limiting

Current Limits

  • Query Results: Maximum 10,000 rows per query
  • Session Timeout: 5 minutes inactivity, 60 minutes maximum
  • Concurrent Connections: One session per user
