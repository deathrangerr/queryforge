Environment Variables

Frontend Configuration (.env)

Located in project root. All variables must be prefixed with VITE_.

# Application Branding
VITE_APP_NAME=QueryForge
VITE_APP_SHORT_NAME=DB Client
VITE_APP_LOGO=🗄️

# Backend API
VITE_API_URL=http://localhost:3002

# Session Timeouts (milliseconds)
VITE_INACTIVITY_TIMEOUT=300000    # 5 minutes
VITE_MAX_SESSION_AGE=3600000      # 60 minutes
Note: Changes to .env require frontend restart (npm run dev).

Backend Configuration (.env.server)

Located in project root. Contains server-side configuration.

# Server Configuration
PORT=3002
NODE_ENV=development

# Session Secret (CHANGE IN PRODUCTION!)
SESSION_SECRET=your-super-secret-session-key-change-this-in-production

# Session Timeouts (milliseconds)
INACTIVITY_TIMEOUT=300000         # 5 minutes
MAX_SESSION_AGE=3600000           # 60 minutes

# CORS Configuration
FRONTEND_URL=http://localhost:5173

# Optional: Redis Session Store (for production)
# REDIS_URL=redis://localhost:6379
# REDIS_PASSWORD=your-redis-password
Security Warning: Always change SESSION_SECRET in production! Use a strong random string (32+ characters).

SAML Configuration

saml-config.json

SAML Identity Provider configuration.

{
  "entryPoint": "https://your-idp.example.com/sso/saml",
  "issuer": "your-app-name",
  "callbackUrl": "http://localhost:3002/api/auth/saml/callback",
  "cert": "YOUR_IDP_CERTIFICATE_HERE",
  "identifierFormat": "urn:oasis:names:tc:SAML:1.1:nameid-format:emailAddress"
}

How to Get SAML Configuration

  1. Access IdP Dashboard: Navigate to your SAML identity provider
  2. Download Metadata: Get SAML metadata XML from IdP
  3. Extract Certificate: Copy the X509Certificate value
  4. Get Entry Point: Copy the SSO URL from metadata
  5. Set Callback URL: Configure in both your IdP and saml-config.json

Example: Fetching Metadata

curl -s "https://your-idp.example.com/saml-metadata" > metadata.xml

Database Configuration

Supported Databases

PostgreSQL

  • Driver: pg
  • Default Port: 5432
  • Connection: User credentials
  • Features: Full support

MySQL

  • Driver: mysql2
  • Default Port: 3306
  • Connection: User credentials
  • Features: Full support

Oracle

  • Driver: oracledb
  • Default Port: 1521
  • Connection: User credentials
  • Features: Basic support

Connection Parameters

Parameter Description Required Example
type Database type Yes postgres, mysql, oracle
host Database server hostname Yes localhost, db.example.com
port Database server port Yes 5432, 3306, 1521
database Database name Yes mydb, production
user Database username Yes dbuser
password Database password Yes ********
Security: User credentials are never stored. They exist only in the session and are cleared on logout.

Installation & Setup

Prerequisites

  • Node.js 18+ and npm
  • Access to database servers (PostgreSQL/MySQL/Oracle)
  • SAML 2.0 identity provider configured
  • SSL certificates (for production)

Step 1: Clone and Install

# Clone repository
git clone <repository-url>
cd dbclient

# Install dependencies
npm install

Step 2: Configure Environment

# Copy example files
cp .env.example .env
cp .env.server.example .env.server

# Edit configuration files
nano .env
nano .env.server
nano saml-config.json

Step 3: Start Services

# Terminal 1: Start backend
npm run server

# Terminal 2: Start frontend
npm run dev

Step 4: Access Application

  • Frontend: http://localhost:5173
  • Backend: http://localhost:3002
  • SAML Callback: http://localhost:3002/api/auth/saml/callback

Troubleshooting

Common Issues

SAML Authentication Fails

  • Verify certificate in saml-config.json (no headers/footers)
  • Check callback URL matches in both IdP and config
  • Ensure issuer matches expected entity ID
  • Check server logs for SAML errors

Database Connection Fails

  • Verify database server is accessible
  • Check firewall rules allow connection
  • Confirm credentials are correct
  • Ensure database driver is installed

Session Expires Too Quickly

  • Increase INACTIVITY_TIMEOUT in .env.server
  • Check activity monitoring is working
  • Verify session secret is set

CORS Errors

  • Verify FRONTEND_URL in .env.server
  • Check credentials: 'include' in fetch requests
  • Ensure CORS middleware is configured
